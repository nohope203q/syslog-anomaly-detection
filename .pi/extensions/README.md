# Extensions

Project này không dùng TypeScript extension riêng.

Lý do: yêu cầu của topic được đáp ứng bằng cấu hình `.pi` gồm agent, prompts,
skills, chain và các script Python chạy thật. Thư mục này được giữ lại để chứng
minh nhóm đã kiểm tra phần extension và không cần mở rộng thêm cho pipeline
hiện tại.
